Creation process and prompt
  1. Describe an original mask, helmet or accessory.
  2. Generate the 3D mesh, or ask a coding AI for a Blender script that builds and exports it.
  3. Export one static GLB with embedded PNG/JPEG textures.
  4. Choose the file above, test model motion, adjust the fit and then start your camera.

Sources and scope

Jeeliz detects face position, scale, rotation and mouth opening. This lab uses one face. The tiger jaw follows mouth opening; the werewolf uses a static mesh. Orbit and Prism are original geometric designs. Custom models use uniform scaling. Tiger uses its original demo calibration. Dog ears and muzzle use calibrated head-local attachment parents; the helmet and dog use a depth-only head proxy to hide rear surfaces. This approximate proxy is not a scan of your head. Live fit, camera compatibility and speed need a real camera check. Model branding and original provenance remain; commercial model clearance has not been established.
