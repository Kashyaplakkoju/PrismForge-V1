# PrismForge Studio V1 Community Edition

A free development release of PrismForge's native Android-to-Windows camera
studio, based on the October 10 V1 checkpoint.

Includes the Windows x64 portable app, debug-signed Android companion, public
source, setup/build/privacy guides, original starter filters and offline colour
packs, dependency notices and download checksums.

This release retains USB/Wi-Fi camera input, Windows camera inputs, colour/LUT
tools, lighting, touch-up, backgrounds, accessories and bounded local model
import. It is supplied as-is for education, experimentation and feedback.
Windows binaries are unsigned; Android uses development signing. No specific
FPS, latency or universal receiving-app compatibility is guaranteed.

Private crown copies, the unused Standard-licensed visor, personal media,
credentials, logs, build caches, V2 and old VCamdroid executables are excluded.
The public source retains its upstream MIT license; asset/dependency terms
remain separate. Read the accompanying notices.

Download the Windows ZIP and APK, then follow `GETTING-STARTED.md` inside the ZIP
or `docs/GETTING-STARTED.md` in the repository. Verify each download against
`SHA256SUMS.txt`. Report issues with software versions and reproduction steps.
